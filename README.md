# RoomSync: Smart Campus Classroom Management System

**Team Spider** | Build With AI: DevOps 2026, GDG on Campus, DDUGU

**Members:** Minakshi Pandey, Shraddha Agrahari

## About
One source of truth for every room and schedule change at IET and Deeksha Bhawan. Faculty find free rooms and book them in a few clicks, and the system refuses any overlapping booking. Only the affected students are notified, and they must acknowledge the notice. Every change is saved in an audit trail.

## Features
- Clickable floor plans for IET and Deeksha Bhawan
- Room search by building, floor, date, time, seats and room type
- Booking with room, student group and teacher clash checks
- Targeted notices by branch, year and section, with acknowledgement
- Student, Faculty and Admin roles
- Audit trail with hash-chain verification
